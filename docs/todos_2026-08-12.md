# TODOs — Code Review Follow-ups (2026-08-12)

Findings from a full-codebase review (backend `api/`, frontend `csv-table-hub-main/`, `build/` shell loaders, CI/infra).

## High severity

- [x] **XSS in PDF/print export** — `csv-table-hub-main/src/lib/export.ts:74-105`. Fixed 2026-08-12: added `escapeHtml()`, applied to the title and every interpolated header/cell in `rowsToHtmlTable`/`printHtml`.
- [x] **Code injection in SQLite loader** — `build/csv/loader_sqlite.sh:31-39`. Fixed 2026-08-12: column names sanitized to `^[a-z_][a-z0-9_]*$` (load aborts if unachievable) and always identifier-quoted (`"…"` / `` `…` ``) with embedded-quote escaping.
- [x] **Weak table-name sanitization at the loader entrypoint** — `build/csv_loader.sh:120-124`. Fixed 2026-08-12: now collapses any non-`[a-z0-9_]` run to underscore and validates against the same strict regex `csv_utilise.sh` uses, aborting with a `--table` suggestion if unsafe.
