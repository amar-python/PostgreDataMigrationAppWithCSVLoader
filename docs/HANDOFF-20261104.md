- CI platform: **Azure DevOps** is the source of truth. The repo stays on GitHub; Azure DevOps connects to it through a service connection (created by Amar in Azure DevOps; not yet done).

- Runners: hosted agents for API, SQL and UI tests; a self-hosted agent for the offline (OFF) suite.
- Coverage gate: move `api/services` coverage into the DB-backed gate job, with floors for the three loaders.
- Formula injection: apply the same guard to XLSX as to CSV.
- Dynamic mode: confirm inferred types before table creation, and add a provenance flag.
